# Dead Group Finder 2.0

ابزار پایتونی برای کشف لینک گروه‌های عمومی از جست‌وجوی وب و پایش پیام‌های جدید در گروه‌هایی که ربات با اطلاع مدیر به آن‌ها اضافه شده است.

## محدودیت قطعی تلگرام
Bot API تاریخچه گروه‌های دلخواه را نمی‌خواند. این برنامه آخرین پیام قبل از اضافه‌شدن ربات را حدس نمی‌زند. زمان آخرین پیام فقط از وقتی ثبت می‌شود که ربات پیام جدیدی را دریافت کند. لینک‌های کشف‌شده در وب تا زمان بررسی فقط «نامزد» هستند.

## امکانات
- جست‌وجوی کم‌سرعت Bing RSS برای لینک‌های عمومی t.me
- ثبت دستی لینک و حذف موارد تکراری
- SQLite و خروجی CSV
- ثبت زمان پیام‌های جدید در گروه‌های تحت پایش
- گزارش فعال/کم‌فعال/بدون پیام مشاهده‌شده
- پنل خصوصی تلگرام با کنترل شناسه مالک
- بدون api_id/api_hash و بدون کتابخانه خارجی
- ذخیره نکردن متن پیام و اطلاعات فرستنده

## نصب ویندوز
1. Python 3.11+ را نصب کن و Add Python to PATH را فعال کن.
2. install_windows.bat را اجرا کن.
3. .env.example را به .env کپی و TELEGRAM_BOT_TOKEN و OWNER_IDS را پر کن.
4. run_windows.bat را اجرا کن.
5. به ربات /start بفرست.

## فرمان‌ها
/help, /status, /scan, /discover عبارت, /addlink لینک, /candidates, /verify, /tracked, /report, /setrange 2 90, /keywords, /addkeyword عبارت, /delkeyword عبارت, /auto on|off, /export

## پایش گروه
ربات را فقط با اجازه مدیر گروه اضافه کن. برای دریافت پیام‌های گروه باید Privacy Mode از BotFather غیرفعال شود و سپس ربات دوباره به گروه اضافه شود. گروه باید از زمان شروع پایش پیام جدید داشته باشد تا تاریخ آخرین پیام مشاهده شود.
