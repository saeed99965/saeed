# Saeed Projects

## Dead Group Finder 2.0

Telegram public-group link discovery and consent-based activity monitoring. The project archive and Persian documentation are in [dead-group-finder/](dead-group-finder/).

**Telegram limitation:** this tool cannot read the historical messages of arbitrary groups through Bot API. It can discover candidate public links on the web and track new messages only in groups where the bot has been added with message access.
